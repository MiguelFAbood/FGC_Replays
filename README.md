# Replays HUB

Replays HUB is a fighting game replay website concept for browsing match replays and submitting replay details. It uses a dark, cyber-inspired visual style and adapts to mobile screens.

## Pages

- **Home (`index.html`)** - replay archive landing page with a match preview and player/game details.
- **Upload (`upload.html`)** - form for entering a replay title, YouTube link, game, players, and characters.
- **Contact (`contact.html`)** - contact form for sending a message.
- **Login (`login.html`)** - login form concept.

## Run locally

This is a static HTML and CSS site. Open `index.html` in a web browser to view it. No build step or dependencies are required.

## Project files

- `styles.css` - shared layout, visual styles, and responsive mobile breakpoints.
- `logo.png`, `icon.png`, `kulabluewhitewide.png` - site logo, favicon, and background artwork.
- The HTML files contain the individual pages.

## Current status

The pages and forms are front-end only. Forms do not currently submit data to a server, and the login, search, and replay-loading interactions are not connected to backend functionality.
